# Kod Editör

Android için VS Code benzeri kod editörü. Editör motoru olarak VS Code'un kendi motoru **Monaco** kullanılıyor.

## Özellikler
- 40+ dil için renklendirme, otomatik tamamlama, parantez eşleştirme
- Dosya gezgini: yeni dosya/klasör, yeniden adlandırma, kopyalama, silme
- Sekmeler, otomatik kaydetme, kaldığın yerden devam
- ▶ **Çalıştır:** HTML (CSS ve JS dosyalarıyla birlikte), tek başına JS ve Markdown önizleme, konsol çıktısı
- Telefon klavyesi için ekstra tuş çubuğu: Tab, oklar, `{ } ( ) [ ] < > ; = "` …
- Bul/değiştir, satıra git, biçimlendir, komut paleti, yazı boyutu, satır kaydırma, mini harita
- Telefondan dosya içe aktarma ve telefona kaydetme

## İndir
`apk` dalındaki **KodEditor.apk** dosyası her zaman son sürümdür.

## Derleme
`main` dalına her gönderimde GitHub Actions Monaco'yu indirir, APK'yı derler ve `apk` dalına koyar.
